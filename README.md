# TOON RADAR

만화 · 웹툰 · 그래픽노블 · 애니메이션 · AI 영상 창작자를 위한 **기회 레이더**.

👉 **https://simsangyoon.github.io/toon-radar/**

## 무엇이 들어있나

| 탭 | 내용 |
|---|---|
| 📅 공모전·어워드 캘린더 | 공모전·어워드·지원사업·페스티벌을 **모집(접수) 기간 기준**으로 정리 |
| 🏢 플랫폼·출판사 | 연재 플랫폼·출판사·에이전시·펀딩 등 공개 투고 창구 |
| 🎥 리뷰어·미디어 | 리뷰·소개를 노려볼 매체와 큐레이션 채널 |
| 📰 트렌드·인기 콘텐츠 | 웹툰 / 애니메이션 / AI·영상 분야별 시장 지표 |

## 원칙

- **공개된 공식 창구만** 싣는다. 개인 이메일을 추측해서 넣지 않는다.
- 접수 시기는 **연도별로 바뀌므로** 카드의 공식 페이지에서 최종 확인해야 한다.
- 확인되지 않은 규정은 "공식 요강 확인"이라고 밝히고, 지어내지 않는다.

## 갱신

`index.html` 한 파일로 동작한다(외부 의존성 없음). 내용을 고친 뒤 커밋·푸시하면 GitHub Pages에 바로 반영된다.
페이지 상단 제목 아래의 `build` 표시로 어느 버전을 보고 있는지 확인할 수 있다.
